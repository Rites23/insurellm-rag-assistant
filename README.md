# Insurellm RAG Assistant

Enterprise Retrieval-Augmented Generation (RAG) application that enables accurate question answering over organizational knowledge bases using Pinecone vector search and OpenAI language models.

![Insurellm RAG Assistant Demo](https://github.com/user-attachments/assets/91bc5a60-cda4-4230-88f6-3dfcf339994c)

## Overview

Insurellm RAG Assistant is an AI-powered insurance chatbot that uses RAG architecture to retrieve information from a custom knowledge base and generate accurate responses.

The application can answer questions about:
- Insurance products
- Claims processes
- Company policies

## Technology Stack

- Python
- LangChain
- OpenAI
- Pinecone Vector Database
- Gradio
- Hugging Face Spaces

## Features

✅ AI-powered question answering  
✅ Document-based retrieval  
✅ Semantic search using vector embeddings  
✅ Knowledge-grounded responses using RAG
